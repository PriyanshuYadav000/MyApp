## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/PriyanshuYadav000/MyFirstApp.git
```

### 2. Navigate to the project

```bash
cd MyFirstApp
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the Expo development server

```bash
npx expo start
```

### 5. Run on Android

Start an Android emulator using Android Studio, then press:

```bash
a
```

Your application should open in the Android emulator.
